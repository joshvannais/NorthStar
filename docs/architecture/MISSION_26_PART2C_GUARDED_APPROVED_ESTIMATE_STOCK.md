A stale empty receipt carries no invented source timestamp. A historical receipt is never silently rewritten.

Capture reuses migration 211's genuine tenant decision order, writer fence, exact coverage epoch, 1,000-pin and 262-KB fail-closed bounds, immutable receipt and idempotent replay. The paid owner/admin capture and read routes call only migration 211's runtime entry points in a read-committed transaction. The database checks subscription, onboarding, session, role, CSRF, tenant, idempotency, purpose, target, cutoff and source currentness while holding the same-tenant writer fence. The routes cannot create an estimate, appointment, quote or forecast.
