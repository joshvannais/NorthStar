# Mission 26 Part 9C — named pipeline scenario prerequisite

The unmounted `namedPipelineScenarioCandidate` reuses Part 6B's exact cents-and-millionths pipeline calculation. For each preliminary or approved-but-unbooked estimate, a caller supplies adverse, base and favorable conversion-weight assumptions, each with a reason code and claimed source kind/digest/record time no later than the as-of cutoff. The result names the three corresponding category totals and retains the per-estimate weights and claimed reasons. Changing a weight or source citation changes the digest. The labels describe **alternative assumptions for an open-pipeline value**, not different facts, booking probabilities, earned revenue or statistical percentiles. “Favorable” has the highest assumed pipeline value; it is not a favorable cost scenario. Booked work remains excluded.

The attribution is caller-supplied and **not authenticated**. A researched claim is not a verified company conversion rate; an estimator-declared assumption is not an approved policy. The source snapshot, coverage, price status and review identity are also unverified in this pure helper. It returns `forecastIssued: false`, `sourceAuthenticated: false`, `assumptionSourcesAuthenticated: false` and `probabilityCalibrated: false`. An incomplete source yields unavailable scenario totals rather than a zero. No route, saved run, monetary forecast, provider call, customer output or automatic action is introduced. This is a narrow prerequisite, not final Part 9C acceptance.

Future integration must authenticate each same-tenant estimate and current revision, source permission, as-of completeness and the assumption's author, date, applicability and revision. Mission 25's approved learning may later inform weights, but only through a reviewed tenant-private calibration policy. A scenario variation must retain its source and explicit changed assumption; no blanket percentage applied to an entire estimate may masquerade as a causal method change. Part 9B's calibrated ranges remain a separate statistical claim, and Part 11 owns immutable issued runs and corrections. Tests cover named arithmetic, provenance identity, input-order reproducibility, unavailable coverage and malformed attributions on fictional data only.
