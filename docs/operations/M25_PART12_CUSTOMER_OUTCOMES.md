# Mission 25 Part 12F customer outcome operations

Part 12F records tenant-private advice from already imported and reviewed evidence. An owner or administrator first grants customer outcome permission for one current CRM source and one current communication source. A later observation selects one NorthStar estimate plus exact reviewed estimate references from both sources.

The observation reports four independent states:

- Lead uses the exact lead reference recorded on the single current issued-estimate record.
- Appointment uses the exact appointment reference recorded on that same issued-estimate record.
- Issued estimate preserves its current recorded source state, including `unknown`.
- Customer response uses a uniquely latest inbound explicit or human-reviewed intent, or explicit satisfaction evidence.

Delivery does not prove a customer response. Outbound communication and provider-classified intent do not become verified customer outcomes. A missing relationship, no current record, more than one current record or a tied latest response remains clearly unavailable. One unavailable dimension does not erase another dimension that has exact evidence.

Every saved observation pins both current source-permission periods, both reviewed estimate links, the current NorthStar estimate basis, all source records considered and the calculation version. Corrections, tombstones, permission changes, reviewed-link changes and target changes require a refreshed observation. Revocation hides derived history. Granting a source again starts a new source period and does not revive earlier evidence or observations.

The result is advisory. It does not edit a customer, lead, appointment, estimate, schedule, price, message, imported record or company policy. This API-only slice adds no rendered owner surface. Slices G-K remain mandatory for scope and project outcomes, available financial outcomes, calibration, lifecycle controls and the complete Learning Center experience.

No live provider, provider credential, private production account, production migration, deployment, physical-device review or manual assistive-technology review is claimed.
