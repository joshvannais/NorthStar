## Failure and correction record

The original source reproduces sales-share1FTE and Month3 ongoing-payroll rejection; both corrected. Initial writer browser runs exposed a floating checkbox, orphan mobile borders/detail spacer and overly precise customer text. Final CSS explicitly overrides inherited column flex direction; the final browser geometry assertion tests the actual inline alignment. The generic scalar sweep also exposed valid future payout dates being rejected by the unrelated Legacy comparison on a short forecast. Legacy failure is now isolated in its Advanced comparison and cannot block canonical results. Its first harness attempt read stale hidden error text as an active failure; the harness now requires the visible `show` validation state and verifies baseline restoration after every field.

A prefreeze route fingerprint run correctly failed when writer source regeneration overlapped its queued execution. That is not a waived mismatch. Final verification is serial, and `verify-investor-revision.cjs` checks unchanged source hashes around every job; only that complete green receipt can support the final freeze. A scalar-sweep assertion also initially omitted the documented normalization of plan weights; the test now independently divides each perturbed weight by the sum of its three entered weights.

No provider quotations, real customer evidence, real financing, tax advice or legal distribution authority were produced by these tests. Tests establish specified arithmetic/interaction boundaries, not investor readiness.
