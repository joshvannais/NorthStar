## Layout and behavior

Materials use per-line groups, aligned quantities/unit prices/costs and plan total. Exact existing rounding text remains as a full-width note. Equipment results show actual recorded identity, task/status and a single requirement/specification pair; missing specifications stay missing and source disclosures remain. Travel trip results gain grouped/padded rows and logistics amounts; measurements, costs, omissions and source caveats remain unchanged. USD amounts use dollar symbols through the shared existing formatter; other currency codes, invalid-value behavior and signed scenario handling remain intact. Units such as US liquid gallons are not currencies.

CAPELLA scenario dt/dd pairs have semantic row wrappers, including long labels and negative amounts. Mobile values remain right-aligned/unbroken while labels wrap. Pricing's existing Refresh Estimate Review and Review Scope And Price buttons move into the active pricing action group, with original nodes/listeners and comment anchors restored before renderer replacement or collapse. No duplicate buttons or cloned handlers. Desktop fits the five actions on one row; mobile uses the existing44px minimum touch targets and12px gaps. Price submission, confirmation, stale/replay handling and source review are unchanged.
