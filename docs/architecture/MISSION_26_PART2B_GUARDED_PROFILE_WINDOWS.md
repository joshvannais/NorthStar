# Mission 26 Part 2B: guarded current Business Profile windows

Status: isolated, unreleased bounded integration candidate. Corrected code head `55d5722d` passed independent read-only review with no P0–P3 findings; final documentation-head review remains pending. Full Part 2B remains open.

The paid `GET /api/v1/forecast/reporting-windows` route derives a local reporting window from the current active Business Profile after account, tenant and forecast-read authorization. It reuses the released `timeSeriesWindows` domain projection and the existing canonical Business Profile reader, and recomputes the normalized profile hash before trusting the read. The response pins the profile ID, version and hash, local dates, IANA time zone, UTC boundaries, elapsed minutes and known or unknown business open minutes. Only an explicit tenant-wide scope is supported; the route does not accept an unverified service or geographic filter. Raw profile data is never returned.

The returned calendar is a **projection using the active profile at read time**. It is not proof that the same hours, area or time zone applied to an earlier month. The response explicitly withholds historical-calendar verification, observation coverage, source eligibility and forecast issuance. A later Business Profile change requires reevaluation; no saved-run currentness is claimed. This route creates no source snapshot, time-series feature, forecast or dashboard value.

Mounted disposable-PostgreSQL tests exercise the actual paid route with an active profile and known hours, exact profile pins and calendar bounds, owner access, other-tenant separation, member/anonymous denial, private no-store response, and rejection of malformed or broadened service/area queries. Controlled faults in the disposable profile's raw content and normalized hash verify that valid owner input receives source-unavailable rather than request-invalid. The existing pure Part 2B tests retain DST and unknown-hours arithmetic coverage. Full Part 2B still needs authorized historical/as-of profile periods, comparable source observations, profile correction propagation and independent acceptance. CI, private production, provider, physical-device and live historical evidence are not claimed.
