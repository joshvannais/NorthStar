# Mission 25 imported labor-duration outcomes

Migration `086_canonical_imported_labor_outcomes.sql` and the guarded external-labor learning routes compare one current adopted labor plan with current normalized work intervals for the same reviewed external job. Every opaque job and worker reference must have a current owner-reviewed same-tenant match. Overlapping intervals fail review.

An owner or administrator first grants the separate `imported_labor_duration_variance_v1` purpose consent while source consent is current. Each observation explicitly confirms the comparison and pins the estimate, adopted revision and labor plan, source consent, reviewed job match, all reviewed worker matches, every imported record and the calculation version. A source correction, tombstone, target change, match revision or consent change makes prior advice stale. Revocation hides derived runtime results. Re-granting source consent does not revive the purpose consent or prior matches.

The result is a deterministic planned-versus-recorded worker-hour advisory. It does not change an estimate, rate, schedule, payroll record, worker profile or business policy. Applying any changed operating assumption remains a separate future human-authorized workflow.

This package is API-only. It adds no rendered owner interface. The later owner experience must separately pass plain-language wording, focus order, keyboard operation, mobile layout, theme parity and founder visual review before it can be called complete.
