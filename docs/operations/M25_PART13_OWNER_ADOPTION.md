# Mission 25 Part 13F owner adoption

Part 13F lets the current company owner adopt one exact relative planning multiplier from the current saved Part 13E proposal preview. The authority is deliberately narrow: labor, travel, vehicle and equipment, and material multipliers are separate per service, measure and comparison basis. Connected financial percentages remain reference-only, scope remains unavailable, and no absolute amount is inferred.

Every adoption pins the exact registry version, registry digest, preview digest, selected measure digest, prior planning revision, actor session, confirmation and request identity. A retry is successful only while that exact adoption remains current and its source selection remains current. A newer registry version, source correction, permission change or newer planning revision retires the earlier retry.

Planning values use an immutable revision history. Only the owner can adopt or roll back a value. A rollback can restore one exact earlier revision or leave the value unset. Rollback remains available when the source proposal is stale or its permission has been revoked so the owner can recover without reviving or trusting retired learning evidence.

The adopted value stays visible if its learning source later needs review. It is marked accordingly and remains in effect until the owner explicitly adopts another current value or rolls it back. Part 13G owns future correction, revocation, deletion and proposal-supersession propagation; this slice does not make those events mutate the saved planning truth.

The authority changes only the versioned service planning multiplier. It does not rewrite an estimate, price, schedule, job, customer, asset, material record, connected financial record, business profile, provider record or company policy. Runtime can execute only the guarded selection preview, adoption, rollback and read entries. It cannot read the underlying table or execute its trigger and projection helpers.
