# Mission 25 Part 12I business calibration operations

Part 12I lets a current owner or administrator review patterns in accepted external customer, project and financial outcomes. It requires a separate calibration permission that points to the current outcome-learning permission. Customer calibration uses one exact CRM and communication source pair; project and financial calibration each use one exact source.

A proposal requires at least five current reviewed outcomes for one service and uses at most 100. Each observation has equal weight. The sample manifest records the exact observation, source evidence and relationship identity used. Corrections, deleted source records, reviewed-link changes, company-target changes and permission changes make an earlier proposal stale.

The dimensions stay independent:

- Customer calibration reports exact lead, appointment, issued-estimate and customer-response distributions.
- Project calibration reports contract change, signed change-order value, project duration and project-delivery state separately.
- Financial calibration reports external recorded revenue, collection, realized cost and margin separately.

Numeric results show a median and the middle half of the reviewed sample. A monetary dimension is unavailable when current values use more than one currency. A categorical advisory is unavailable when the most frequent value is tied. Missing evidence never becomes zero, and currency conversion, unit conversion, causality and operational adoption are not inferred.

Revocation hides ordinary reads and repeated-request reads. A later grant begins a new calibration period and does not revive earlier proposals. Runtime can use only the guarded permission, proposal and read entries. Tables and calculation helpers are withheld.

This slice adds no rendered page. It connects to no provider, uses no provider credential and changes no customer, lead, appointment, estimate, project, change order, job, invoice, payment, price, schedule or company policy. Part 12J lifecycle authority, Part 12K Learning Center work and Mission 27 native financial authority remain unavailable.
