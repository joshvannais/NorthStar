# Mission 26 Part 6A — guarded approved-price event source

This additive source receipt reads the immutable Mission 24 human-decision ledger for one paid tenant. It preserves every bounded approval, amendment and withdrawal through a server-minted as-of cutoff, including estimate and decision IDs, revision/previous-decision lineage, recorded time, exact price text, currency and decision digest. It does not alter a Mission 24 decision. The receipt is immutable, has a content digest, and is available only through owner/admin capture and read functions with current session, tenant and paid-access checks. The capture requires CSRF, a serializable transaction and an idempotency key. Runtime cannot read the underlying table or source helper directly.

The snapshot is capped at 1,000 events, 256 estimates and 256 KiB. An oversized tenant fails closed; it is never silently truncated into a false complete history. A future bounded paging or partitioning design would need to prove complete coverage before numerical promotion. A replay of an existing idempotency key returns the original receipt, even after new decisions. New decisions require a new capture and do not rewrite old receipts.

This is historical **approved commercial price** evidence, not earned revenue, invoicing, collections, or a forecast. The snapshot preserves mixed currency and withdrawal facts for a later method to interpret; it does not sum unlike currencies or decide which event is commercially effective at a booking. It also does not authenticate Mission 22 bookings. Part 6A's existing calculation contract and the Part 12A paid journey remain open until a guarded adapter proves event semantics, complete coverage, deterministic future method, mounted permission, immutable run, currentness, explanation and reviewed handoff. Synthetic PostgreSQL tests prove this source boundary only. Live tenant forecast accuracy remains unverified.
