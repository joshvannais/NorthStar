# Mission 25 Part 13G lifecycle propagation

Part 13G carries current correction, removal, permission and proposal state into the owner-adopted planning-value read. The current owner sees whether the exact adopted source is still current, whether a newer saved proposal exists, whether permission ended or began again, and whether connected evidence changed or became unavailable.

The check follows the exact planning revision, saved proposal version, preview digest, selected measure digest and current permission period. Earlier planning revisions are marked as history after a later owner decision. A later permission period never makes an earlier source current again. A corrected or removed source cannot be treated as unchanged evidence.

The adopted multiplier remains in effect when its source needs review. Lifecycle propagation does not silently replace, remove, recalculate or roll back that multiplier. Only a new owner adoption or explicit owner rollback creates a planning-value revision. The response states this boundary and gives the owner a plain explanation of the current review state.

Runtime continues to use only the guarded planning selection, adoption, rollback and read entries. The lineage helper is withheld from runtime and public access. The change adds no estimate, price, schedule, job, asset, material, connected financial, provider, business-profile or company-policy mutation. The paid and isolated-demo experience remains Part 13H, and native NorthStar financial truth remains Mission 27.
