# Mission 25 Part 13A job outcome graph

Part 13A creates the canonical tenant-private relationship between one current NorthStar estimate and exact accepted per-job outcome observations. The graph is lineage only. It does not copy or combine outcome values.

An owner or administrator first grants separate permission to review job outcomes together. A graph then requires two to 100 exact current observations across at least two domains. Accepted node classes are native and imported labor, imported travel, native and imported equipment, native and imported materials, reviewed external customer outcomes, reviewed project outcomes and reviewed external financial outcomes. Each node is re-read through its existing guarded authority and must belong to the same canonical estimate.

The saved record pins the current graph-permission revision and digest, current estimate target manifest and digest, every observation identity, revision, digest, source digest and bounded locator, the calculation version and the deterministic request identity. Equal values never collapse distinct provenance. Unsupported or duplicate nodes fail closed.

A correction, tombstone, source or purpose permission change, reviewed-link change or estimate-target change makes prior graph evidence stale and hides its node manifest. Revoking graph permission hides the period. A later grant starts an empty period and does not revive an old graph. Exact concurrent retries remain idempotent only while the saved graph is still current.

Runtime receives only guarded consent read/write and graph read/build functions. It cannot read graph storage or execute resolver and validation helpers. Graph creation changes no customer, lead, job, appointment, estimate, price, schedule, dispatch decision, labor entry, asset, material, project, financial record or company policy.

This slice adds no rendered page. Freshness and conflict evaluation, complete job summaries, cross-job proposals, impact preview, owner adoption, propagation and the final paid/demo experience remain mandatory Slices B-H. Native NorthStar invoice, payment, collection and accounting truth remains unavailable until Mission 27.

No provider connection, provider credential, private production account, production migration, deployment, physical-device review or manual assistive-technology review is claimed.
